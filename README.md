# Portfolio v3

Personal portfolio built with Next.js 16, TypeScript, TailwindCSS v4, and Framer Motion.

## Sections

- **Hero** — animated intro with floating tech icons and gradient CTA
- **About** — bio, focus areas, stats, and quick facts
- **Projects** — featured project cards with GitHub links
- **Skills** — categorized tech stack with real dev icons
- **Contact** — direct contact channels (email, GitHub, Discord, location)
- **Footer** — navigation, social links, and copyright

## Extra features

- Loading screen on entry
- Scroll progress bar + themed custom scrollbar
- Scroll-reveal animations via Framer Motion
- Mobile-responsive navbar with scroll-spy

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```
